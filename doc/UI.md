# سیستم طراحی و UX

وضعیت: پیش‌نمایش طراحی R02 ساخته و از نظر فنی بررسی شده؛ در انتظار بازخورد ظاهری مالک است. دامنه صفحه‌ها در [PRODUCT.md](./PRODUCT.md) و معیارهای AA در [QUALITY.md](./QUALITY.md) است.

## هویت و اجزا

سبک مدرن و مینیمال با glass کنترل‌شده. رنگ، فونت، spacing، radius، shadow، motion و لایه‌بندی از token مشترک. رنگ و دارایی برند فقط از BUSINESS_CONFIG؛ theme paletteها token-based باشند. shadcn/ui پایه رفتار و اجزا است، ظاهر فروشگاه اختصاصی طراحی می‌شود.

تم روشن، تاریک و سیستم؛ انتخاب کاربر پایدار و بدون flash/خطای hydration تا حد ممکن با راهکار سازگار SSR. contrast روی پس‌زمینه واقعی سنجیده شود. glass برای هدر/منو/لایه شناور؛ قیمت، متن و فرم سطح خوانا دارند. fallback بدون blur ضروری است.

## چندزبانگی و responsive

### قرارداد تم اجرایی

ThemeProvider محلی در `src/components/theme-provider.tsx` هیچ script در render ندارد. hook محلی `useTheme` انتخاب light/dark/system را ارائه می‌کند؛ external store با useSyncExternalStore، matchMedia و storage event همگام می‌شود. preference در حافظه کلاینت هنگام تغییر locale حفظ و در صورت دسترسی در localStorage با کلید theme ذخیره می‌شود؛ شکست storage تعامل همان document را متوقف نمی‌کند.

bootstrap کوچک از تابع مستقل `src/lib/theme.ts` و defaultTheme تنظیمات مرکزی به `public/brand/theme-init.js` تولید می‌شود. در root layout به‌صورت external async script با پشتیبانی resource deduplication خود React قرار دارد؛ script خام inline و next-themes حذف شده‌اند. CSS لوگو همان tokenهای تأییدشده است. html دارای data-scroll-behavior مناسب navigation است. این روش نباید با تزریق inline script به Provider یا مخفی کردن console error جایگزین شود.

`lang/dir` صحیح روی سند؛ logical properties و isolation متن‌های mixed. آیکون جهتی آینه شود، تصویر محصول و لوگو خیر. متن انگلیسی طولانی، نام فارسی چندخطی، عدد بزرگ، فونت fallback و breakpoints بر اساس محتوا تست شوند. موبایل از ابتدا، بدون scroll افقی غیرضروری؛ جدول مقایسه الگوی دسترسی مناسب داشته باشد.

## حالت‌های لازم هر قابلیت

| حالت | رفتار |
| --- | --- |
| loading | skeleton با ابعاد پایدار؛ اعلان مناسب بدون مزاحمت |
| empty | توضیح روشن و اقدام بعدی واقعی |
| error | پیام قابل اصلاح و retry در صورت ایمن بودن |
| submitting | جلوگیری از ارسال تکراری و حفظ داده فرم |
| success | تأیید واضح و مرحله بعد |
| stale/conflict | توضیح تغییر قیمت/موجودی و بازبینی پیش از خرید |
| unauthorized/expired | ورود مجدد با حفظ مسیر بازگشت امن |
| offline | نگه داشتن ورودی ممکن؛ ادعای ثبت سفارش موفق نشود |
| unavailable | جایگزین روشن برای محصول/سرویس غیرفعال |

جست‌وجو، فیلتر، انتخاب variant، سبد و checkout باید قابل استفاده با صفحه‌کلید و touch باشند. focus visible، dialog focus management، label، خطای فیلد و اعلام وضعیت لحاظ شوند. hover تنها راه دسترسی نباشد. animation رعایت reduced-motion و کنترل حرکت داشته باشد.

## محتوا

لحن واضح و یکدست فارسی/انگلیسی؛ ترجمه واقعی و بدون متن hardcode. تصویر محصول منطبق با کالای واقعی، alt توصیفی و مجوز استفاده مشخص؛ بنر تولیدی با عکس واقعی محصول اشتباه نشود. نظر، شمار فروش، تخفیف و badge اعتماد بدون پشتوانه نمایش داده نشوند. نخست نمونه خانه/محصول برای اصلاح مالک آماده شود، سپس الگو به صفحات دیگر گسترش یابد.


## اجرای طراحی R02

- پالت و مونوگرام DS/سبد همان انتخاب تأییدشده؛ سطوح روشن آرام و تیره سرمه‌ای با hero تیره ثابت برای کنتراست تصویر/متن.
- Vazirmatn محلی از Fontsource، وزن‌های 400/500/600/700؛ import اصلی مطابق درخواست مالک در globals.css. جزئیات در FONTS.
- هیروی محصول‌محور با تصویر اختصاصی، عنوان بزرگ و CTA به مجموعه؛ تصاویر هر سه محصول مفهومی‌اند و با اعلام واضح پیش‌نمایش نمایش داده می‌شوند.
- دسته‌ها، search/filter درون‌صفحه‌ای، empty state، modal بومی dialog با Escape و بازگشت focus، منوی موبایل با dismiss و keyboard؛ بدون قیمت یا سفارش جعلی.
- انیمیشن با GSAP و ScrollTrigger: ورود بخش‌ها، پارالاکس محدود تصویر هیرو/روایت و پیشرفت اسکرول. reduced-motion حرکت را خاموش می‌کند؛ محتوای SSR بدون JavaScript مخفی نیست.
- فضای تصویر hero و thumbnail جدا شده تا preload/تشخیص LCP به تصویر lazy پایین صفحه نسبت داده نشود. Hero eager/high-priority و بقیه تصاویر lazy؛ WebPها محلی‌اند.

خانه و صفحات مستقل مجموعه، دسته‌ها، درباره و سه محصول مفهومی آماده REVIEW هستند؛ اتصال کاتالوگ به دیتابیس و امکانات تجاری محصول در R05 ساخته می‌شود. نبود violation در axe به معنی گواهی کامل WCAG نیست؛ screen-reader و ماتریس کامل مرورگر در ارزیابی نهایی باقی‌اند.


## بازنگری R02 — کانتینر، تم، حرکت و ناوبری

- عرض محتوای همه صفحات ۹۰٪ viewport؛ فاصله‌ها و ارتفاع هیرو جمع‌وجورتر شدند. سرمه‌ای اصلی #0B1F3A در هیرو و footer هر دو تم حضور دارد؛ لوگو همان نسخه تأییدشده است.
- کنترل تم فقط toggle روشن/تاریک است؛ گزینه خودکار در UI نیست. قبل از انتخاب صریح کاربر، تم به‌صورت خودکار از سیستم پیروی می‌کند. انتخاب قبلی و همگام‌سازی بین تب‌ها حفظ می‌شود.
- زبان با پرچم SVG و نام در منوی بازشونده است؛ Escape و کلیک بیرون منو را می‌بندند. تغییر زبان مسیر صفحه محصول و query دسته را حفظ می‌کند و RTL/LTR صحیح می‌ماند.
- خانه تنها صفحه سایت نیست: مجموعه، دسته‌ها، درباره و محصولات مسیر مستقل دارند. کلیک تصویر/عنوان محصول صفحه آن را باز می‌کند؛ دکمه پیش‌نمایش سریع dialog جداگانه دارد.
- GSAP پس از hydration همان صفحه فعال می‌شود. marker داخل main هر صفحه مالک scope است؛ اجرای آن از layout مشترک ممنوع است چون ممکن است پیش از hydration محتوای streaming، DOM را تغییر دهد. cleanup در تغییر مسیر و matchMedia فعال است. reduced-motion حرکت و transform را پاک می‌کند.

وضعیت طراحی همچنان REVIEW است تا مالک نسخه بازنگری‌شده را ببیند.


## اصلاح عرض و انتخاب ظاهر — R02

طبق بازخورد تازه مالک، shell در همه breakpointها دقیقاً width:90% با margin-inline:auto است؛ سقف ثابت ۱۱۲۰ و محاسبات فاصله قبلی حذف شدند. حالت سیستم پیش‌فرض باقی است، اما گزینه جداگانه خودکار از UI حذف و روشن/تاریک با switch دسترس‌پذیر ارائه می‌شود. پس از انتخاب صریح، ترجیح کاربر ذخیره می‌شود.

منوی پالت مستقل چهار انتخاب سرمه‌ای/سبز اصلی، بنفش، آبی اقیانوسی و رز دارد. پالت، رنگ primary، ring، حاشیه‌ها، سطوح muted و تأکید هیرو را تغییر می‌دهد. سرمه‌ای هیرو و هندسه لوگو حفظ می‌شوند. انتخاب پالت در localStorage ذخیره و با bootstrap خارجی پیش از hydration بازیابی می‌شود؛ تغییرات بین تب‌ها همگام‌اند و نبود دسترسی به storage باعث توقف کنترل‌ها نمی‌شود.

وضعیت ظاهری REVIEW باقی است؛ این اصلاح کاتالوگ تجاری یا انتشار نیست.


## تیتر اختصاصی و حرکت — بازنگری R02

SignatureHeading تیتر مشترک همه صفحات و بخش‌هاست: یک heading معنایی با متن پیوسته و نشانه تزئینی سه‌خطی شبیه موج صدا. GSAP متن را آرام وارد و خطوط نشانه را با stagger کوتاه آشکار می‌کند. حروف فارسی برای انیمیشن جدا نمی‌شوند؛ بدون JS متن خوانا است و در reduced-motion حرکت ندارد. h1 هیرو حداکثر ۴۸px دسکتاپ و ۳۶px موبایل، h1 صفحات حداکثر ۳۸px و h2 بخش‌ها حداکثر ۳۲px است.

آیکون ماه و خورشید داخل track سوئیچ‌اند؛ thumb و آیکون‌ها transition دارند. تغییر light/dark رنگ سطوح، متن و border را طی ۴۰۰ms نرم می‌کند. class موقت theme-transition پس از ۴۲۰ms پاک می‌شود؛ در reduced-motion اضافه نمی‌شود. bootstrap اولیه transition ندارد.

Lenis 1.3.27 (stable بررسی‌شده در registry رسمی) اسکرول wheel را با lerp 0.12 نرم می‌کند و از ticker موجود GSAP استفاده می‌کند؛ callback و instance در تغییر مسیر یا reduced-motion پاک می‌شوند. touch طبیعی می‌ماند. dialog و منوهای داخلی از smoothing مستثنی‌اند. anchor offset متناسب با header است؛ CSS رسمی Lenis وارد شده تا با smooth بومی تداخل نکند. منابع: [راهنمای رسمی Lenis](https://github.com/darkroomengineering/lenis).

کانتینر ۹۰٪ و پیش‌فرض سیستم حفظ شده‌اند. وضعیت طراحی همچنان REVIEW است.


## پاس مهارت‌های طراحی — ۲۰۲۶/۱۰/۳۱

اصلاح UI و موشن با مهارت‌های تازه انجام شد؛ گزارش Before/After، جهت طراحی، شواهد و محدودیت‌ها در [UI_REVIEW.md](./UI_REVIEW.md) است. لوگو/پالت‌ها/کانتینر ۹۰٪ حفظ شدند. متن خواناتر، یک CTA در هیرو، دسته‌ها بدون شماره تزئینی، ناوبری جاری، تبلت مستقل و منوی زبان داخل قاب اصلاح شده‌اند. revealها یک‌بار اجرا می‌شوند و حرکت والد/تیتر روی هم نمی‌افتد. نشانه موج صدا فقط h1 را امضا می‌کند. زمان toggle برابر 180ms و transition رنگ محدود 220ms است. این قرارداد جدید بر توضیح 400ms قبلی اولویت دارد.

R02 همچنان REVIEW است؛ تأیید ظاهری مالک و کار روی کالا/خرید واقعی باقی‌اند.


پذیرش نهایی ۲۰۲۶/۱۰/۳۱: مالک نسخه بازبینی‌شده را تأیید کرد. R02 اکنون DONE است و وضعیت REVIEW بالاتر مربوط به پیش از پذیرش است. commit/push همین خروجی مجاز شد؛ شروع R03 نیز مجاز است.

## پیشرفت R04 — ۲۰۲۶/۱۰/۳۱

فرم‌های fa/en برای ثبت‌نام، ورود، تأیید، ارسال مجدد، فراموشی و بازیابی؛ حساب، نشست‌ها و تغییر رمز اضافه شدند. هویت و کانتینر۹۰٪ حفظ شد. focus، label، خطای کنار ورودی، نمایش رمز، autocomplete، pending و پاسخ عمومی ایمیل وجود دارند. فرم‌های پرتکرار انیمیشن ورودی تأخیردار ندارند. بررسی Axe و overflow موبایل/دسکتاپ پاس است؛ این بررسی معادل ممیزی جامع کل سایت نیست.
