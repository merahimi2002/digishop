# لوگوی SVG و تم

نسخه برداری با path و circle واقعی، بدون نوشته، فونت، تصویر raster یا وابستگی بیرونی؛ بازطراحی هندسی از کانسپت DS و سبد انتخاب‌شده است، نه trace پیکسل‌به‌پیکسل. منبع نهایی: `assets/brand/digishop-mark.svg`. طرح‌های اولیه PNG و پیش‌نمایش مستقل قدیمی هنگام آماده‌سازی GitHub حذف شدند.

مقادیر رنگ در BUSINESS_CONFIG ثبت‌اند و CSS از همان فایل تولید می‌شود. حالت روشن سرمه‌ای/سبز و حالت تاریک سفید آبی/سبز روشن است. منطق تغییر رنگ، تغییر نقش توکن‌هاست؛ کل لوگو با filter معکوس نمی‌شود.

برای تغییر با تم سایت SVG باید **inline** یا به‌صورت کامپوننت React با همان pathها رندر شود؛ در Next.js هنگام تبدیل، attributeها به JSX سازگار تبدیل و اندازه و نام دسترس‌پذیر از props گرفته شوند. متغیرهای `--logo-base` و `--logo-accent` از والد به inline SVG ارث می‌رسند. `.dark` یا `data-theme="dark"` توکن‌ها را تغییر می‌دهد. برای تک‌رنگ هر دو متغیر را `currentColor` قرار دهید. نمونه:

```css
.brand-mark {
  --logo-base: var(--brand-logo-base);
  --logo-accent: var(--brand-logo-accent);
}
.brand-mark--mono {
  --logo-base: currentColor;
  --logo-accent: currentColor;
}
```

در `<img src="...svg">` یا next/image متغیر CSS والد به داخل SVG منتقل نمی‌شود؛ فایل مستقل فقط از prefers-color-scheme سیستم پیروی می‌کند. برای انتخاب دستی تم از inline SVG استفاده کنید. `data-theme` روی خود SVG نیز fallback روشن/تاریک را انتخاب می‌کند.

لوگو نباید با تغییر زبان mirror شود. اگر کنار نام متنی یا داخل لینک دارای نام قابل دسترس است، تصویر تکراری decorative با aria-hidden باشد؛ در استفاده مستقل نام دسترس‌پذیر لازم است. پس‌زمینه فایل شفاف است. favicon کوچک و نسخه تک‌رنگ پیش از انتشار در اندازه واقعی بررسی شوند.

## اتصال اجرایی R01

کامپوننت واقعی src/components/brand-mark.tsx هندسه را از خروجی generator می‌گیرد؛ CSS اصلی رنگ در src/app/brand.generated.css از BUSINESS_CONFIG تولید می‌شود. asset نهایی حفظ شده است. لوگوی تطبیقی در تست تم و screenshots واقعی بررسی شد؛ تصاویر آزمون محلی قابل تولید مجددند و در مخزن قرار نمی‌گیرند. انتخاب لوگو و رنگ توسط مالک تأیید شده است.
