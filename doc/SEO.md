# SEO فنی و محتوایی

وضعیت: الزامات پیاده‌سازی؛ هیچ رتبه یا نمره‌ای تضمین نمی‌شود. معیار عددی و performance در [QUALITY.md](./QUALITY.md) است.

## سیاست صفحه

| صفحه | سیاست اولیه |
| --- | --- |
| خانه، دسته و محصول منتشرشده و کامل | index و canonical همان ترجمه |
| جست‌وجوی داخلی و ترکیب فیلترهای بی‌ارزش | noindex؛ جلوگیری از crawl space بی‌پایان |
| حساب، سبد، checkout و پنل | noindex؛ پنل/حساب با auth واقعی |
| staging و preview | محافظت دسترسی و noindex |
| محصول موقتاً ناموجود | صفحه معتبر با availability درست؛ حذف خودکار از index نشود |
| محصول حذف دائمی | جایگزین مرتبط واقعی با redirect یا 404/410 طبق تصمیم محتوا |

محتوای اصلی SSR؛ metadata محلی، عنوان روشن، description منطبق، canonical بدون پارامترهای غیرضروری. صفحات pagination سیاست مستقل معتبر داشته باشند؛ همه به صفحه اول canonical نشوند مگر محتوای واقعاً معادل.

مسیرهای `/fa` و `/en` با hreflang متقابل و x-default سازگار؛ فقط ترجمه موجود و منتشرشده معرفی شود. sitemap از منابع canonical و فعال ساخته شود. تغییر slug با redirect به URL جدید و بدون زنجیره. robots برای کنترل crawl است، نه حفاظت داده؛ URL مسدودشده از crawl ممکن است noindex آن خوانده نشود.

Product/Offer و Breadcrumb از داده واقعی صفحه تولید شوند؛ نظر و امتیاز ساختگی درج نشود. نام سازمان، دامنه و تصویر اشتراک‌گذاری از BUSINESS_CONFIG. داده structured با validator مناسب و HTML نهایی بررسی شود. بررسی Search Console و داده میدانی پس از انتشار با دسترسی مالک انجام می‌شود.

## پیشرفت R04 — ۲۰۲۶/۱۰/۳۱

صفحات auth، account و admin دارای metadata noindex هستند. صفحات خصوصی احراز هویت سروری و APIهای no-store دارند. لینک حساس auth از fragment به حافظه فرم منتقل می‌شود؛ هیچ token در query مسیرهای عمومی یا metadata درج نمی‌شود.
