## ماشین وضعیت

| State | معنی | شرط خروج |
| --- | --- | --- |
| TODO | هنوز پیش‌نیاز آماده نیست | رفع وابستگی |
| READY | پیش‌نیاز و معیار پذیرش آماده | شروع واقعی |
| IN_PROGRESS | در حال اجرا | خروجی قابل بررسی یا مانع مشخص |
| REVIEW | نیازمند نظر یا بازبینی مشخص | ثبت نظر؛ سکوت تأیید نیست |
| VERIFYING | بررسی معیار پذیرش | evidence موفق یا اصلاح |
| BLOCKED | مانع مشخص با شناسه پرسش/خطا | ثبت رفع مانع و برگشت READY |
| DONE | معیار پذیرش با شواهد پاس شده | بازگشایی فقط با دلیل |

مسیر معمول: TODO → READY → IN_PROGRESS → VERIFYING → DONE. در صورت نیاز به نظر، IN_PROGRESS → REVIEW → IN_PROGRESS/VERIFYING. خطای تست از VERIFYING به IN_PROGRESS برمی‌گردد. کار فعال با مانع مستند به BLOCKED می‌رود؛ اطلاعات آینده مانع کار مستقل نیست. هر task یک state دارد؛ phase فقط با اتمام همه taskهای اجباری DONE می‌شود. تغییر وضعیت و بازگشایی در EXECUTION ثبت شود. قابلیت خارج از دامنه به‌دروغ DONE نشود. این سند دستور استفاده از sub-agent نیست.

## تیتر اختصاصی و حرکت — بازنگری R02

SignatureHeading تیتر مشترک همه صفحات و بخش‌هاست: یک heading معنایی با متن پیوسته و نشانه تزئینی سه‌خطی شبیه موج صدا. GSAP متن را آرام وارد و خطوط نشانه را با stagger کوتاه آشکار می‌کند. حروف فارسی برای انیمیشن جدا نمی‌شوند؛ بدون JS متن خوانا است و در reduced-motion حرکت ندارد. h1 هیرو حداکثر ۴۸px دسکتاپ و ۳۶px موبایل، h1 صفحات حداکثر ۳۸px و h2 بخش‌ها حداکثر ۳۲px است.

آیکون ماه و خورشید داخل track سوئیچ‌اند؛ thumb و آیکون‌ها transition دارند. تغییر light/dark رنگ سطوح، متن و border را طی ۴۰۰ms نرم می‌کند. class موقت theme-transition پس از ۴۲۰ms پاک می‌شود؛ در reduced-motion اضافه نمی‌شود. bootstrap اولیه transition ندارد.

Lenis 1.3.27 (stable بررسی‌شده در registry رسمی) اسکرول wheel را با lerp 0.12 نرم می‌کند و از ticker موجود GSAP استفاده می‌کند؛ callback و instance در تغییر مسیر یا reduced-motion پاک می‌شوند. touch طبیعی می‌ماند. dialog و منوهای داخلی از smoothing مستثنی‌اند. anchor offset متناسب با header است؛ CSS رسمی Lenis وارد شده تا با smooth بومی تداخل نکند. منابع: [راهنمای رسمی Lenis](https://github.com/darkroomengineering/lenis).
