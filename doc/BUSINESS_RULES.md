## وضعیت‌های دامنه پیشنهادی

- محصول: draft → published → archived؛ بازنشر پس از کنترل کامل بودن داده.
- سفارش: pending_payment → confirmed → processing → completed؛ cancelled فقط از وضعیت‌های مجاز. لغو و return بعدی در مشخصات transition جدا تکمیل شوند.
- پرداخت: pending → verified / failed / expired؛ verified → partially_refunded / refunded فقط با تأیید provider و ثبت ledger.
- ارسال: unfulfilled → preparing → shipped → delivered؛ failed/returned با دلیل و مسیر رسیدگی.
- رزرو: active → consumed / released / expired؛ هر رزرو فقط یک پایان مؤثر دارد.

این فهرست حالت‌ها پیاده‌سازی نیست. در R07 جدول کامل from/event/guard/to/side-effect و آزمون‌های آن قبل از اتصال درگاه تکمیل می‌شود. مالیات، گردکردن تخفیف، جمع‌پذیری کوپن، زمان رزرو و خرید مهمان نباید با حدس وارد فروش واقعی شوند.
